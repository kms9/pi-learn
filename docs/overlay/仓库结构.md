# 仓库结构

`pi_case` 是 **独立 overlay git 仓库**，不是 `earendil-works/pi` 的 fork。现有 GitHub 仓以 **submodule** 接入，overlay 只钉 commit SHA。

| 路径 | 层 | overlay 里记什么 |
|------|----|------------------|
| `docs/` | wiki | 全文 |
| `AGENTS.md`、`README.md`、`scripts/` | schema / 工具 | 全文 |
| `docs-zh/` | 译文镜像 | 全文 |
| `pi-dev/` 等 | raw / submodule | `.gitmodules` + gitlink SHA |

清单见根目录 `.gitmodules`。

## 维护上游

```bash
./scripts/sync-submodules.sh
# overlay 若出现 gitlink 变化，确认后 commit 以钉死新 SHA
python3 scripts/sync-zh.py
python3 scripts/sync-zh.py --accept pi-dev/packages/... --record-head
```

`sync-zh.py` 退出码 1：译文 stale、缺文件、或 HEAD 相对 `docs-zh/manifest.json` 漂移。

## GitHub

推 overlay（含 `.gitmodules` 和 gitlink）。协作者：

```bash
git clone --recurse-submodules <overlay-url>
git submodule update --init --recursive   # 已 clone 过时
```
