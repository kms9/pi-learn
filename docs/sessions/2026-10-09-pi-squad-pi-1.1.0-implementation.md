按影响评估顺序完成兼容优化、三角色真实验证及 Pi 1.1.0 升级验收。

## 达成了什么

实施及验收进行中，尚未声明原 89 项在 Pi 1.1.0 全通过。change 为 `pi-squad-pi-1-1-0-compatibility`。

- 正式激活精确切换到 `pi-coding-agent/1.1.0` / TUI，TS 与 Go 常量同步。
- `Invocation` 的 settled 使用实际 aborted 标记，true 优先于缓存的 completed；原 generation/session/binding、idle/no-pending、manual compact 延迟保护保留。
- Controller doctor 支持官方 managed launcher，解析选定 release 的真实 runtime 入口；核对 launcher、release、CLI 与 package 版本，保留实际入口/hash 匹配。非法 release 名、缺 release、入口越界拒绝。
- schema 2 observer 保存 aborted；probe reader 的成功生命周期要求明确 aborted=false。缺字段、true、旧 profile 与错误入口报告不就绪。
- README/USAGE 与版本化验收入口已更新。普通/integration Go 构建、Pi 1.1.0 公共声明严格类型检查、严格 OpenSpec 校验与文档链接检查通过。未运行单元测试。

### 已完成的真实运行

使用新的 Herdr `wA`，所有正常 Pi 从项目 cwd 启动。独立 Controller 与 Dashboard，counter/summer/reviewer 三 Role 起步，随后增加 backend/frontend/researcher/auditor、Team Leaders 和 reviewer Secondary。Controller 为 `/tmp/pi-squad-110-controller-integration`，隔离库 `/tmp/pi-squad-110-upgrade.sqlite`；未停止用户服务或委派开发 Agent。

- 第一条 standalone count Task 真实读取 numbers fixture，提交 count=3 与 immutable read artifact，正常 completed/released。
- 已完成三轮数字 Team workflow：真实 counter/summer、独立 reviewer 接受精确结果版本/hash、结构化 Leader decision 与其 own settled 后最终 Gate 完成。
- result_proposed 后在真实 Pi 按 Esc，Task/Attempt 为 interrupted，error=aborted，资源 released；取消没有成为正常 completed。
- provider proxy 在真实请求注入 503；原生重试等待期间 Esc 后 Task interrupted/released。此分支 Pi 保留 error outcome，不能假称该分支 aborted=true；保护目标是非 completed 与安全释放。第一次观察太迟、重试已耗尽的准备失败保留。
- 正常真实 probe 在 managed launcher 与具体 release 的 doctor 中均 formal_execution_ready=true；取消/缺字段/旧版/错误入口的受控报告不就绪。
- Team 父 invoke summer → yield → 原 Attempt continuation → parent result 与独立 review 真实运行。首轮 Leader 多创建对 parent-policy child 的 direct review，正确遭 REVIEWER_NOT_AUTHORIZED，Run needs_review 后显式取消；失败保留。明确 review 仅针对 parent 后，重测 Run completed/released。
- 新 reviewer 进程为 Secondary，原 Primary 不变。空闲 counter 的原生 /new 更新 session/binding_epoch，稳定 agent/runtime/primary_epoch 不变。
