# 2026-10-09 核对 Pi Squad 与 Pi 1.1.0 的版本状态

## 用户要做什么

确认当前 `pi_squad` 是否已经升级到最新 Pi 1.1.0。

## 达成了什么

- 结论: 当前默认 Pi CLI 已为 `1.1.0`，但 Pi Squad 尚未完成 Pi 1.1.0 适配；宿主安装版本与插件兼容范围是不同对象。
- 本次实际执行 `command -v pi` 得到 `/Users/logo/.local/bin/pi`，`pi --version` 输出 `1.1.0`。[npm 包页面](https://www.npmjs.com/package/%40earendil-works/pi-coding-agent?activeTab=code) 同时显示发布版本 `1.1.0`。此处是本次核对快照，不代表后续版本状态。
- [插件 package.json](../../pi_squad/package.json) 的自身版本仍为 `0.1.0`；它不是 Pi 宿主的版本号。
- [Extension doctor](../../pi_squad/extension/doctor.ts) 的 `HOST_PROFILE` / `HOST_VERSION` 仍为 `pi-coding-agent/1.0.1` / `1.0.1`，`inspectHost()` 精确比较 `VERSION !== HOST_VERSION`，`capabilities()` 遇到错误会抛出异常。因此按当前代码，在 Pi 1.1.0 下激活 Squad 会产生 `SQUAD_HOST_UNSUPPORTED`。
- [Controller doctor](../../pi_squad/controller/project/doctor.go) 的 `HostProfile` / `HostVersion` 同样限定 `1.0.1`。[README](../../pi_squad/README.md) 与 [USAGE](../../pi_squad/USAGE.md) 仍登记精确 Pi 1.0.1/TUI 支持范围。
- 本地 `pi-dev/packages/coding-agent/package.json` 仍为 `1.0.1`。最近一次插件提交 `c0214d5` 的主题为阶段 04 与 Pi 1.0.1 兼容完成；此前的 89/89 验收不能证明 Pi 1.1.0 兼容。
- 本次只核对版本命令、源码和已有记录，未启动模型或功能验收，未修改插件、安装环境或上游 submodule，未提交。
