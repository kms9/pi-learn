# 怎么学写插件

默认学的是 [[concepts/extension|Extension]]。Harness 是 Extension 挂上去的那一层运行时，完整对照见 [[harness对照讲解|Harness 对照讲解]]。

## 阅读顺序

1. API：`docs-zh/pi-dev/packages/coding-agent/docs/extensions.md`
2. 实现导读：`docs-zh/pi-dev/packages/coding-agent/docs/extensions-impl.md`
3. 例子：`pi-dev/packages/coding-agent/examples/extensions/`  
   先 `hello.ts`、`permission-gate.ts`、`dynamic-tools.ts`、`reload-runtime.ts`
4. 中文注释副本：`docs-zh/pi-dev/packages/coding-agent/src/core/extensions/`（`types` → `loader` → `runner` → `wrapper`）
5. 接线：上游 `pi-dev/packages/coding-agent/src/core/agent-session.ts`
6. 打包：`docs-zh/pi-dev/packages/coding-agent/docs/packages.md`
7. 第三方样本：`herdr-pi-extensions/`、`agent-tools/`（行为参考，不是官方 API）

`docs-zh` 里的 `.ts` **不能编译、不能提回上游**。

## 运行时

```
factory(pi) → loader 发现/jiti/commit → Extension 登记表
           → runner.bindCore → 事件按加载顺序
           → wrapper 给工具注入 ctx
```

`project_trust` → `session_start` → `resources_discover` → `input` → `before_agent_start` → agent 循环 → `session_shutdown`

TUI 上的一段对话是 [[concepts/session|Session]]（一份 JSONL + 活的 `AgentSession`），不是 `conversation`。一轮用户输入是 agent run（到 `agent_settled`）；其中每次 LLM+工具是 turn。

## 写的时候

- 工具 schema 用 typebox；字符串枚举用 `StringEnum`
- 状态放 tool result `details`，`session_start` 从 branch 重建
- 改文件走 `withFileMutationQueue()`
- 输出截断（约 50KB / 2000 行）
- 能 `/reload` 的放 `~/.pi/agent/extensions/` 或 `.pi/extensions/`；`pi -e` 只试跑
- 不要改 `pi-dev/` 里的官方 examples 当作品

```bash
pi -e ./my-extension.ts
```
